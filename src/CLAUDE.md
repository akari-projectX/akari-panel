# akari-panel/src — Rust 后端

扁平模块，由 `lib.rs`（crate `akari_panel`）声明；`main.rs` 只是二进制入口（CLI + 启动装配，`use akari_panel::…`）。拆库的原因：`bench/`（M2）要驱动真实代码路径；新模块加进 `lib.rs`，不要加进 `main.rs`。全局状态是 `state::AppState`（`Arc<Inner>` 克隆句柄）。

## 约定

- 错误：handler 返回 `Result<_, ApiError>`；`sqlx::Error`/`anyhow::Error` 自动转 500，并记录日志，不向客户端泄露细节。
- SQL：运行时 `sqlx::query*`（非编译期宏），手写 SQL，列名与 migrations 保持一致。
- 状态变更：`apply_*` 在调用方事务内写库 + bump；通知由触发器在同一事务内发出（见根 CLAUDE.md「收敛」）。
- 测试里持有池连接的对象（`PgListener`、未结束的事务）必须在 `db.drop()` 前释放，否则 `pool.close()` 会永远等待。
- W26 金标准 `w26_golden_tests.rs` + `testdata/w26/`：模板渲染（含全部错误）、凭据生成/调整、state hash 输入与输出、三种订阅格式整份正文、校验结果，逐字节比对；随机性经 `entropy`（测试可固定种子）。改了任何一项输出都必须是有意的（`AKARI_UPDATE_GOLDEN=1` 重写并审查 diff）。
- W20 测试 `w20_tests.rs`（真库 + HTTP）：订阅 token 加密存储/可取回/轮换/按哈希查找/旧账户不轮换/触发器/管理员读取审计/日志无 token（捕获 tracing）、首个邀请码自动生成。
- 测试：`traffic`、`api`、`grpc`、`db`、`plans`（reconcile 全流程、周期重置、到期、并发、HTTP）、`entitle` 有单元测试与真库测试（`testdb.rs`）；`sub` 三格式（links/clash/sing-box）整份快照 + UA 分流/分桶测试、`web::tests::prefix_gate_rejections_are_byte_identical`（所有拒绝与规范 404 字节同构）已补；改任何客户端格式必须同时改快照。
- **覆盖率门（W13；W16 加 `billing/{coupons,ledger,commission}`；W17 加 `tickets`、`alerts/{mod,eval,channels}`；W22 加 `trafficlog`；W28-a 加 `entrances`）**：`traffic`/`trafficlog`/`enforce`/`entitle`/`entrances`/`plans`/`billing/{orders,catalog,api,alipay,methods,coupons,ledger,commission,manual,coupon_batches,refund}`、`batch`/`export`/`csvx`（Ops）的生产代码行覆盖率（真库测试计入，内联 `#[cfg(test)] mod` 之后不计）每个 ≥ 90%（CI job `coverage`，`make coverage`）；改这些模块要带测试，阈值只升不降。仅测试/fuzz 用的内省放在测试模块之后的 `#[cfg(any(test, fuzzing))]` 模块（如 `traffic::introspect::check_invariants`）。
- advisory lock 是**全库**的：所有测试 schema 共用 `akari.entitlement`，测试里持有它的事务必须尽快结束（未结束的事务还会让 `db.drop()` 永远等待）。

## 内置常量（W25/R39，`config.rs`）

原 panel.toml 的内部旋钮，现为常量（`Limits` 汇总；改值 = 改代码 + 测试）：失联租约 `LEASE_SECONDS` 24h；节点/流量合理性上限 `TRAFFIC_MAX_RATE_BYTES_PER_SEC`、`TRAFFIC_NODE_MAX_RATE_BYTES_PER_SEC`（1.25e9）、`DEFAULT_NODE_BURST_SECS` 120、departed 宽限 900s（`traffic::DEFAULT_DEPARTED_GRACE_SECS`）；agent 证书 `DEFAULT_CERT_VALIDITY_SECS` 90 天、注册 token `ENROLL_TOKEN_TTL_SECS` 24h、注册限速 10/60 每 600s；安装链接 `INSTALL_TOKEN_TTL_SECS` 1h、限速 20/600s；订阅限速 120（/64）/30（token）每 600s；`MAX_CONCURRENT_DOWNLOADS` 8；ask `TLS_ASK_RATE_PER_SEC` 20；告警轮次 `ALERTS_EVAL_INTERVAL_SECS` 30s；测速 `PROBE_TIMEOUT_MS` 5000、`PROBE_ATTEMPTS` 3、「立即测速」冷却 30s；中转健康 `ENTRANCE_HEALTH_INTERVAL_SECS` 60、`ENTRANCE_HEALTH_FAILURES` 3；官方发布公钥 = `src/release-keys.txt`（akari-agent `release-keys.txt` 的逐字节副本，`updates::OFFICIAL_RELEASE_KEYS`，CI `release-keys` job 对比 agent main）。运维可改的设置不做常量：放 `panel_settings`（或其所属设置表，如 `alert_settings.telegram_api_url`）+ 系统设置 UI，NULL = 内置默认。
